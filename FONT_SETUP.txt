ENSEMBLE PORTABLE FONT SETUP

Copy your original font files into:
    Ensemble\Fonts\

Exact filenames:
    Handel Gothic Regular (H2).ttf
    Conduit ITC Regular (ODST).otf

Do not install them into Windows. Build Ensemble normally.

Directory.Build.targets copies them to the output Fonts folder, and Ensemble
loads them directly from there. When distributing Ensemble, distribute that
Fonts folder with the EXE and other users will not need to install the fonts.

If the files are absent, Ensemble falls back to system fonts.
